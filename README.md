# 🧠 Brain Tumor Classification Using Deep Learning

An AI-powered Brain Tumor Classification system that classifies MRI brain images using deep learning models and provides real-time prediction through a Flask web application.

---

## 🚀 Features

- Brain MRI image classification
- Deep learning-based prediction
- Image preprocessing pipeline
- Real-time web application
- Performance evaluation and analysis
- User-friendly interface

---

## 🛠️ Technology Stack

- Python
- TensorFlow / Keras
- OpenCV
- Flask
- NumPy
- Pandas
- Matplotlib
